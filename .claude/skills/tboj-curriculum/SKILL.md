# TBOJ 教材編寫與設計 Skill

本 skill 讓任何 Agent（含 subagent）都能為一個主題，產出一套**符合計畫靈魂**的完整教學包。
請嚴格依以下步驟與規格執行。

---

## 0. 最高前提：先讀《設計守則》

動手前，**務必先讀** [`docs/DESIGN_PRINCIPLES.md`](../../../docs/DESIGN_PRINCIPLES.md)。
任何教材都必須通過其腓立比書 4:8 審稿（真實、可敬、公義、清潔、可愛）與紅綠燈規則。
若主題或內容與守則衝突 → **停下、回報，不要硬做**。

---

## 1. 兩軌設計哲學（每個主題都要做兩版）

| | 第一版（傳統取向） | 第二版（AI 時代取向） |
| --- | --- | --- |
| **讀者** | 傳統教師、家長、圖書館館員 | 教會教育者、新式家長、理解 AI 時代的教育者 |
| **核心** | 學科知識 + 孩子能力發展 | 個人發想、提問、解決問題 |
| **衡量** | 學會了什麼、能做出什麼 | 問了多好的問題、怎麼思考 |
| **背誦** | 包含必要的知識記憶 | **刻意不教背誦**——那是 AI 的工作 |
| **教師指引時間表** | **要**（45 分鐘流程表） | **不要**（思考不被鈴聲打斷） |

每個主題盡量對齊計畫的品格目標之一：**同理心** 或 **自我認同**（並可帶出服事最小的、誠實等）。

---

## 2. 必產出的檔案（4 個，缺一不可）

路徑：`content/samples/<topic-slug>/`（slug 用英文小寫連字號，例如 `water-cycle`）

```
content/samples/<topic-slug>/
├── v1-traditional.md      # 第一版教材（給孩子）
├── v1-teacher-guide.md    # 第一版教師指引（含 45 分鐘時間表）
├── v2-future.md           # 第二版教材（給孩子）
└── v2-teacher-guide.md    # 第二版教師指引（不排時間）
```

完成後**務必**更新 `content/README.md` 的目錄結構與範例清單。

---

## 3. 第二版三鐵則（寫 v2 時必須貫徹，並寫進 v2 教師指引開頭）

> 1. **不要限制孩子的想像力。** 再天馬行空的點子都先接住，不評價。
> 2. **不要給標準答案。** 孩子問你，把問題丟回去：「你覺得呢？」
> 3. **問得好，比答得對更值得稱讚。**

v2 教材結構固定為五段：**情境 → 發想 → 提問 → 動手解決 → 反思**。
v2 一律「不打分數、不排名」，評量改為觀察「提問品質」與「是否更敢做自己 / 更有同理」。

## 4. 四個檔案的骨架模板

### 4a. `v1-traditional.md`
```
# 示範教材 · 第一版（傳統取向）｜<主題標題>
> 讀者對象 / 取向：學科知識 + 能力發展 / 適用年級 / 已通過《設計守則》腓 4:8 審稿
## 一、學習目標（3–4 條，最後一條納入品格/同理或自我認同）
## 二、課文（淺白、具體、生活化）
## 三、新詞學習（表格）
## 四、理解問題（檢查學科知識，3 題）
## 五、能力發展活動（動手做）
## 六、品格與<同理心/自我認同>延伸（連回他人或自我價值）
*教師使用提示：…*
```

### 4b. `v1-teacher-guide.md`
```
# 教師指引 · 第一版（傳統取向）｜<主題標題>
> 搭配教材 / 給非本科老師也能上 / 一堂約 45 分鐘 / 已通過審稿
## 一、上課前準備（零成本教具）
## 二、45 分鐘教學流程表（表格：時間 | 階段 | 老師要做的事）
## 三、提問腳本（可照著念；提醒問完先等 5 秒）
## 四、常見卡關與救援（表格）
## 五、評量觀念（呼應守則：不排名、不羞辱，加 6:4）
```

### 4c. `v2-future.md`
```
# 示範教材 · 第二版（AI 時代取向）｜<主題標題>
> 讀者對象 / 取向：發想、提問、解決問題；不在乎答對在乎想深 / 已通過審稿
## 寫在前面（為何此版不背誦：AI 時代要的是會問、會想）
## 一、情境（一個沒有標準答案的真實挑戰）
## 二、先發想（沒有對錯，越多/越誠實越好）
## 三、學會提問（核心：孩子自己想 ≥3 個問題，並分類「查得到 / 只有自己能答」）
## 四、動手解決（設計自己的辦法，無標準答案）
## 五、反思（連回自己與他人，帶出同理或自我價值）
## 給陪伴者的評量觀念（不打分數，看提問與成長）
```

### 4d. `v2-teacher-guide.md`
```
# 教師指引 · 第二版（AI 時代取向）｜<主題標題>
> 搭配教材 / 給教會/新式陪伴者 / 刻意不排時間 / 已通過審稿
## ⚠️ 開始之前，請先讀這一段（放上方第 3 節「三鐵則」）
## 一、準備（幾乎不用準備）
## 二、怎麼帶（流程是流動的，不是時刻表；逐段說明）
## 三、陪想腳本（把答案還給孩子；表格：孩子說 | 你可以回，皆不含答案）
## 四、當你忍不住想糾正/引導時（保護孩子敢想的勇氣）
## 五、怎麼看出成功了（不打分數；觀察提問、同理、是否更敢做自己）
```

## 5. 內容鐵則（紅綠燈摘要）

- 🟢 自己跟自己比的成長；弱勢/偏鄉也能用（免費、低門檻、低頻寬）；培養同理或自我認同。
- 🔴 不比較/排名/羞辱孩子；不背誦取向出現在 v2；不誤導、不誇大；不蒐集兒童個資。
- 語言：淺白、具體、適齡；對缺乏資源的孩子保持尊重，不製造匱乏羞恥。

## 6. 完成後的收尾（提交規範）

1. 更新 `content/README.md`（目錄 + 範例連結 + 對應的品格支柱）。
2. 在 `dev` 分支開發（**不要**直接動 `main`，main 受保護、由人統一以 PR 更新）。
3. commit 本體用英文；**最後加一行中文 `DC-zh:` trailer** 作為 Discord 推播簡述。例如：
   ```
   content: add "<topic>" teaching pack

   <english body>

   DC-zh: 新增主題「<中文主題>」完整四件套教材…
   ```
4. `git push -u origin dev`。
