# TBOJ — The Book of James

> 「在神我們的父面前，那清潔沒有玷污的虔誠，就是看顧在患難中的孤兒寡婦，並且保守自己不沾染世俗。」
> — 雅各書 1:27
>
> 「這樣，信心若沒有行為就是死的。」
> — 雅各書 2:17

TBOJ 是一個以**兒童教育**為核心的計畫，源自雅各書的信念：真實的信仰必須化為行動。我們相信，幫助困苦中的孩子得到公平的教育機會，正是「沒有行為的信心是死的」這句話最具體的實踐。

---

## 🎯 我們要解決的問題

台灣（以及更廣泛的）基礎教育存在結構性的困境：

| 問題 | 現況 |
| --- | --- |
| **教師資源分配不均** | 城鄉差距大，偏鄉與弱勢學生難以取得優質師資與教材 |
| **學校保護機制失能** | 對學生的安全、心理與情感支持系統流於形式 |
| **好老師反而被打壓** | 真正用心的教師在體制中受到排擠，劣幣驅逐良幣 |
| **缺乏同理心與自我認同的培養** | 學校重視成績，卻忽略孩子內在價值的建立與陪伴 |

## 💡 我們的解法

兩條腿走路，**科技降低阻力 + 真人提供溫度**：

1. **以系統降低環境與人為阻力** — 讓每個小學生都能取得最基本的常識與優質的學習內容，不因出身、地區或師資而被剝奪。
2. **以實體輔導員陪伴成長** — 科技無法取代人與人之間的關懷。輔導員負責關心、陪伴、建立孩子的同理心與自我認同。

> 系統解決「規模」與「公平」，真人解決「溫度」與「人格」。兩者缺一不可。

## 🗺️ Roadmap

計畫分為七個階段，由近而遠、由具體而抽象：

### Phase 1 — 推廣 E-learning 輔助教材
建立並推廣數位學習輔助教材，作為降低教育資源門檻的第一步。

### Phase 2 — 教會彌補學校失能機制
以教會（社群）的力量，補足學校在城鄉差距、資源落差、同理心缺口上的失能。

### Phase 3 — 與葉丙成教授合作，反轉教育制度
與教育改革者（如葉丙成教授）合作，從體制面推動教育翻轉。

### Phase 4 — 啟動智能導師與諮商輔導雙軌模式
結合 AI 智能導師（知識傳遞）與真人諮商輔導（情感陪伴）的雙管理模式。

### Phase 5 — 防止系統被惡意利用
設計防護機制，避免有心人利用系統散播惡意內容或傷害孩子。

### Phase 6 — 傳承與迭代機制
設計教育的傳承機制，讓系統能持續迭代進步，而非掩蓋錯誤或讓罪惡一再重演。

### Phase 7 — 思考 Kingdom 的概念
從更宏觀的願景思考整個計畫的最終形態與精神內核。
