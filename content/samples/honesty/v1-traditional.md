# 示範教材 · 第一版（傳統取向）｜說真話的勇氣：誠實

> **讀者對象**：傳統教師、家長、圖書館館員
> **取向**：語文／品德與生活學科 + 孩子能力發展（判斷、口語表達、責任感）
> **適用年級**：國小中年級（3–4 年級）
> **本教材已通過《設計守則》腓立比書 4:8 審稿**

---

## 一、學習目標

讀完這一課，孩子應該能夠：
1. 用自己的話說出「誠實」是什麼意思。
2. 分辨「說真話」和「說傷人的話」的不同——誠實不等於什麼都可以亂講。
3. 說出「做錯事時誠實說出來」會有什麼好結果。
4. 體會：誠實是為了讓人與人之間可以彼此信任。

---

## 二、課文：說真話，需要一點勇氣

打破了杯子、考試考不好、不小心弄壞了別人的東西——這時候，心裡常會冒出一個念頭：

> 「要不要假裝不是我？」

說真話，有時候真的需要勇氣。因為說了，可能會被罵、會不好意思。
可是，**一句謊話，常常要用更多謊話去蓋住它**，最後連自己都記不清楚說過什麼。

誠實，就是**心裡怎麼想、事情實際怎樣，說出來的就是那樣**。

- 做錯了，誠實承認，事情反而比較快過去。
- 別人會慢慢發現：「這個人說的話，可以相信。」

這份「可以相信」，就叫做**信任**。它很難得，一旦說了謊弄壞了，要花很久才修得回來。

> 誠實不是要你把所有想法都大聲講出來。如果真話會傷人，可以選擇**溫和地說、或先不說**，但**不要說假的**。

---

## 三、新詞學習

| 語詞 | 解釋 |
| --- | --- |
| 誠實 | 心裡想的、事情真實的樣子，和說出來的一致 |
| 謊話 | 明明知道不是真的，卻故意那樣說 |
| 信任 | 相信一個人說的話、做的事是可靠的 |
| 承認 | 老實說出「這是我做的」 |

---

## 四、理解問題（檢查語文與判斷）

1. 用你自己的話說說看，「誠實」是什麼意思？
2. 課文說「一句謊話常要用更多謊話去蓋住」，這是為什麼？
3. 如果真話會讓朋友很難過，除了說謊，還可以怎麼辦？

---

## 五、能力發展活動（口語＋判斷）

**「我會怎麼說」情境卡**：老師讀出一個情境，孩子想一想，再說出他誠實又不傷人的回答。

| 情境 | 想一想：怎麼說才誠實，又不傷人？ |
| --- | --- |
| 你不小心打破了同學的水壺。 | |
| 阿嬤煮的菜你不太喜歡，她問你好不好吃。 | |
| 作業沒寫完，老師問你寫好了沒。 | |

請孩子兩兩練習，輪流當「說的人」和「聽的人」，再上台分享一個最難的情境怎麼處理。

---

## 六、品格與同理心延伸

誠實，不只是「不騙人」，更是**讓身邊的人覺得安心**。

- 想一想：當一個人對你說真話，即使是不好聽的真話，你會不會反而更信任他？
- 如果班上每個人都會誠實認錯，這個班會變成什麼樣子？
- 別人誠實地對你說了難說的話，你可以怎麼回應，讓他下次還敢說真話？

> 誠實要付一點代價——可能是面子、可能是一時的不好意思。
> 但它買回來的，是別人對你長長久久的信任。

---

*教師使用提示：本課重點不是「抓說謊的孩子」，而是「讓孩子體會誠實帶來的安心與信任」。當孩子當場誠實承認一件小錯，請先肯定那份勇氣，再談事情本身。*
